# Croquis

App Android para el levantamiento del estado actual de viviendas: plantas, alzados y secciones en DXF y PDF, con una
precisión de ±5 mm. La cámara da la forma; las medidas (cinta, láser tecleado o láser por Bluetooth) dan las cotas, y
un ajuste de toda la casa las hace cuadrar.

Estado: recién creado (2026-11-21), sin código. Plan en `docs/ROADMAP.md`.
